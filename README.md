# suprise

终端里的 **彩虹惊喜动画 + 内嵌 BGM**：3-2-1 倒计时开场，爱心烟花、128 BPM 节拍心跳，最后以 LOVE 大字收尾——适合在终端里给人一个小惊喜。

## 效果四幕

| 时间 | 幕 | 内容 |
| --- | --- | --- |
| 0 – 3s | 虹彩倒计时 | 大字 `3 → 2 → 1` 彩虹倒数 |
| 3 – 7.5s | 虹彩烟花 | 火星升空后炸成爱心，五个位置轮番绽放 |
| 7.5 – 22.5s | 节拍心跳 | 心形随 128 BPM 每拍鼓点缩放，色相绕心形旋转 |
| 22.5s 起 | 终极对冲 | `LOVE` 大字，左右色相相差 180° 对冲，间歇白闪 |

## 实现要点

- 画布 100×40 字符，每帧 20ms（约 50 FPS），ANSI 清屏整体重绘；
- 24-bit 真彩色（`\033[38;2;r;g;b;m`），RGB 由时间驱动的三路正弦波生成，相位互差 120°；
- 心形用隐式曲线 `(x²+y²-1)³ - x²y³ ≤ 0` 逐点光栅化，鼓点冲击用 `sin⁸` 做包络；
- `bgm.flac` 通过 `go:embed` 编入二进制，启动后先等音乐真正开始播放，动画才开始计时。

## 构建与运行

```bash
go build -o suprise
./suprise
```

跨平台：macOS / Windows / Linux（Linux 构建需 ALSA 开发库，如 `apt install libasound2-dev`）。

终端需支持 24-bit 真彩色（Terminal.app、iTerm2、Windows Terminal、VS Code 终端均可）。

## 依赖

- Go 1.26+
- [`github.com/gopxl/beep`](https://github.com/gopxl/beep)：FLAC 解码与音频输出

## 注意事项

- 二进制约 50MB：`bgm.flac`（约 44MB）被完整嵌入；
- 启动即出声，播放前请确认系统音量；背景音乐为单曲，播完不循环；
- 画面在第四幕无限循环，`Ctrl+C` 退出；
- 程序会隐藏终端光标，退出后若光标不显示，执行 `printf '\033[?25h'` 恢复。
